# Lamp — إضاءة بيتك

واجهة متجر عربية لمبات LED منزلية، مبنية بـ Next.js 16 وReact 19 وTypeScript.

## المتجر

- كتالوج تجريبي بثلاثة موديلات افتراضية وقواعد E27 وE14 وGU10.
- بحث وتصفية حسب القاعدة، وترتيب حسب السعر.
- سلة محلية للمعاينة وإدارة الكميات؛ لا يوجد شراء حقيقي أو دفع إلكتروني داخل Lamp.
- تبديل بين الوضعين الفاتح والداكن؛ صور اللمبات تتغير بين مطفأة ومنوّرة.
- التصميم عربي RTL ومتجاوب مع الهاتف.

الصور واقعية لكنها لموديلات افتراضية، والأسعار والمواصفات تجريبية وليست عروضًا تجارية.
قبل النشر خارج Vercel، عيّن `NEXT_PUBLIC_SITE_URL` إلى النطاق الفعلي للموقع.

## التشغيل

```bash
npm ci
npm run dev
```

افتح `http://localhost:3000` في المتصفح.

## التحقق

```bash
npm run lint
npm run build
```
